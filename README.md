# 📞 Freshdesk App Customer Analysis

## 📌 Project Overview
This project focuses on analyzing customer support ticket data from the Freshdesk application to evaluate service performance, identify response and resolution delays, and uncover operational inefficiencies affecting customer satisfaction.

The analysis aims to provide data-driven insights into agent performance, ticket handling time, and support workflow efficiency to help optimize customer service processes.

---

## 🎯 Objectives
- Analyze customer support ticket lifecycle
- Identify response time and resolution delays
- Evaluate agent performance and workload
- Detect service bottlenecks impacting customer experience
- Improve support efficiency through data-driven insights
